3. Glossário Técnico

HTML
Linguagem de marcação utilizada na construção de páginas Web.
CSS
Mecanismo para adicionar estilo a um documento web.
JavaScript
Linguagem de programação interpretada estruturada.
Utilizada principalmente para criar interatividade no lado do cliente.
DOM
Document Object Model
Interface de programação para documentos HTML e XML.
HTTP
HTTPS
Protocolos de transferência de dados entre cliente e servidor.
API
Conjunto de rotinas e padrões estabelecidos por um software para a utilização de suas funções.
URL
Endereço de um recurso na rede.
DNS
Sistema que converte nomes de domínios em endereços IP.
